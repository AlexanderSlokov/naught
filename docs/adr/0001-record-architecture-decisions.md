# 1. Record architecture decisions

**Status:** accepted
**Date:** 2026-09-24

## Context

`ARCHITECTURE.md` closes with a list of settled questions that are not to be
reopened without an ADR. That instruction needs somewhere to point.

## Decision

Architectural decisions are recorded here as numbered Markdown files. An ADR
is immutable once accepted; a decision that changes gets a new ADR that
supersedes the old one, and the old one stays in the repository saying what
was believed at the time.

## Consequences

The settled list in `ARCHITECTURE.md` §10 is enforceable: reversing any of it
means writing the document that explains why.
